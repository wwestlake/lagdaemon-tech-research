# Djehuti Electronics Lab

Djehuti Electronics Lab is the GPL-3.0 electronics design tool track inside the
DjehutiRoute workspace.

It covers:

- schematic capture research
- component databases
- parts sourcing
- SPICE/Xyce simulation workflows
- instruments and dataset views
- Frust math/workbench integration research
- agent-assisted electronics workflows

The license for this app is GPL-3.0. See `LICENSE`.

The MIT router library lives separately under:

```text
libs/djehuti_route
```
