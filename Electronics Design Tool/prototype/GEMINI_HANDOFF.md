## Current Implementation

### Implemented And Tested

- Machine Builder now has an `Add Plot` action that creates a passive N-channel Plot Panel subsystem in the diagram.
- Plot Panel subsystem definitions are generated by `SystemAssembly::makePlotPanelDefinition(int channelCount)`.
- Plot Panel input ports are observable/passive ports. `AssemblyCompiler` skips Plot Panel instances so they do not add circuit elements, devices, or numerical topology.
- Diagram wires into Plot Panel ports are synchronized into operator-console plot channel bindings.
- Plot Panel channel configuration persists in `.machine.json`: channel id, title, signal binding, unit, color, scale, offset, axis range hints, visibility, plot mode, X/Y channel selection, visible history, max samples, and auto-scroll.
- Changing Plot Panel `channels=N` in the inspector resizes the passive diagram instrument from 1 to 16 channels and removes connections to deleted channels.
- Plot Panel bindings follow instance rename/removal behavior through `MachineModel`.
- Saved Plot Panel configuration survives save/load and remains validation-clean in the focused smoke test.
- Adding a wired Plot Panel was verified not to change the simulated motor result.
- Operator console supports multiple named panels in `ControlPanelLayout`.
- Operator console supports compact controls, multiple control/instrument columns, panel selection, panel creation, panel rename, panel removal, and a resizable control/instrument divider.
- Plot recordings are owned by `ControlPanelComponent`, not by the visible widget instance. They survive plot widget rebuilds and switching between operator panels while the console component remains alive.
- Plot Panel UI supports Strip Chart and XY Plot modes using the same recorded samples.
- Strip Chart mode plots visible channels against simulation time with auto-scroll and visible history.
- XY Plot mode plots configured X/Y channels from the same recording buffer.
- Plot UI supports Record on/off, Pause View, Clear, Markers, CSV export, and saved recording export as `.plotrecording.json`.
- Plot trace colors are supported by `PlotSurface::setTraceColours`.
- Plot mode changes made in the plot widget are pushed back into the machine layout and plot subsystem text parameter so saves preserve the selected mode.

### Partially Implemented

- Recording uses `StateSnapshot` simulation timestamps, but acquisition is driven by the control panel timer reading the latest snapshot. This records against simulation time but is not yet a simulation-thread recorder/listener, so very high-rate transitions between UI ticks can be missed.
- Hidden/inactive operator panels continue recording because `ControlPanelComponent` records all configured Plot Panel widgets. Recording when the entire console is closed or destroyed is not implemented.
- Measurement support is limited to the existing PlotSurface marker mode and pan/zoom behavior. Full cursor readouts, deltas, and measurement tables are planned work.
- XY mode currently supports one configured X/Y pair per plot widget. Multiple simultaneous XY pairs are not implemented.
- Operator panels persist and can be created, selected, renamed, and removed. Full GUI assignment of arbitrary existing widgets between panels is not implemented beyond adding new Plot Panels to the active panel and moving widgets to fallback when a panel is removed.
- Detached panels/docking integration is not implemented.
- Gauge/range configuration persistence exists through the existing widget model; a full GUI editor for all plot/gauge channel properties is still planned.

### Planned / Not Implemented

- Compact toolbar cleanup for Machine Builder editing buttons. This is Gemini's first assignment below.
- Native/manual GUI acceptance has not been completed for Plot Panel recording, CSV export, file chooser flows, or panel rename dialog.
- No new custom docking windows for operator panels.
- No simulation-thread, lossless recorder infrastructure.
