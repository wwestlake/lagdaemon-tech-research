# CEL Archive

This directory preserves the retired Creation Executive Language (CEL)
implementation after the Creation Suite adopted FRust as its sole hosted
language.

The archive is research source, not a production dependency. It is retained so
language experiments, historical implementation details, and CEL-specific test
fixtures remain available without keeping CEL in the Suite build graph.

See `ARCHIVE_MANIFEST.md` for the exact origin paths and source commits.
