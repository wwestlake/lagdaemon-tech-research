# 01 - Imperative Language Paradigm

## Focus
Exploring procedural semantics, stack allocation, explicit mutable variables, loops (`while`, `for`), conditional branching, and direct LLVM IR function generation.

## Key Concepts
* Mutable variable bindings (`alloca`, `store`, `load`).
* Control Flow Graph (CFG) generation with basic blocks.
* Stack frames and mutable state management.
