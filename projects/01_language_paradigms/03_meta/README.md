# 03 - Meta Language Paradigm

## Focus
Exploring compile-time code generation, AST reflection, hygienic macro expansion, and compile-time expression evaluation (CTFE) executed via LLVM OrcJIT during compilation.

## Key Concepts
* Macro expansion passes.
* In-memory JIT execution of compile-time logic.
* AST quote / unquote mechanisms.
* Type reflection and code synthesis.
